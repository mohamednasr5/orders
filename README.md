# Enterprise SaaS Order Management System

## النشر على GitHub Pages (Deployment)
هذا المشروع مصمم ليكون متوافقاً تماماً مع **GitHub Pages**.
تم نقل ملف `index.html` ليكون في المجلد الجذري (Root Directory) للمشروع حتى يتعرف عليه GitHub مباشرة.

## الميزات الأساسية:
- **دعم اللغتين (Bilingual):** نظام ترجمة مدمج باستخدام Vanilla JS (عربي/إنجليزي) مع دعم كامل لاتجاهات الشاشة RTL/LTR.
- **توجيه ديناميكي (Routing):** التنقل بين الصفحات بدون إعادة تحميل (SPA).
- **الوضع الليلي:** مدعوم برمجياً عبر المتغيرات (CSS Variables).

## كيفية التشغيل:
1. ارفع كافة الملفات إلى مستودعك على GitHub.
2. اذهب إلى `Settings` -> `Pages` في المستودع.
3. اختر الـ Branch الرئيسي (`main` أو `master`) كـ Source.
4. انتظر دقيقة وسيعمل الموقع مباشرة.
